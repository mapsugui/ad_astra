## Bottom line

No Gaia DR3 non-single-star (NSS) two-body solution is published for the
TOI-2666.01 host. The astrometric-companion channel therefore **neither supports
nor excludes** the eclipsing-binary / companion alternative for this lead: the
result is `inconclusive`, because Gaia's NSS sensitivity is incomplete and an
undetected companion is not excluded. No new object is claimed.

This test does not resolve the ExoFOP note "v-shaped; possible EB" and does not
change the production lead status (`Unverified lead`, which has survived every
production test run so far).

(P = 4.8124683 d, e = 0.053, K1 = 85.77 km/s, significance 1199.6,

earlier attribution is withdrawn; nothing in this campaign depends on it.

## Falsification

The conclusion would change if (a) a significant NSS solution were found for
`2223770483452673408` (a companion already known to Gaia), (b) a resolved
eclipsing binary or a radial-velocity orbit at the host were reported, or (c)
difference imaging placed the event on a blended neighbour rather than the host.
Tests (b) and (c) are not performed here.

## Caveats

- Gaia NSS is not a complete companion census: sensitivity depends on period,
  mass ratio, magnitude contrast and the astrometric solution.
- No NSS solution does not mean "single star".
- This step does not test eclipsing binaries with orbits outside NSS sensitivity,
  nor blended background binaries.
- The target coordinates are copied from the production TOI-2666.01 spec (TOI
  table); the Gaia match is 0.019" from them.
