# Cygnus brand (in progress)

`build_brand.py` generates the logo concepts in `concepts/` and the review sheet `index.html` from the Yale Bright Star Catalogue positions and colours in `design-system/mockups/data/bsc5.csv`. Run `python design-system/brand/build_brand.py`, then serve the folder (`python -m http.server 8769 --directory design-system/brand`) and open `http://127.0.0.1:8769/`.
