# Button

Links styled as actions: `.btn` (outline accent, the default), `.btn--solid` (accent fill), `.btn--quiet` (neutral outline).

- Use `.btn` for downloads and secondary actions; `.btn--quiet` beside it for "Home"-type escapes; `.btn--solid` at most once per view.
- Labels say exactly what happens: "Download", "Browse the repository". A download button carries the file name in a visually hidden span.
- Min height 36px, `radius`, `fs-sm` 500. Solid text is `surface` on `accent` (7.9:1 light, 8.1:1 dark).
