# Badge

Uppercase mono label for type, publication status, availability and origin. Badges classify; they never report test outcomes (use StateChip).

- Variants: default (neutral outline), `--accent` ("Download available" only), `--quiet` (origin, kind, "Linked to source archive"), `--draft` (draft only; `draft` on `warn-wash`), `--withdrawn` / `--restricted` (dashed, `ink-3`).
- Research status is always its own badge on collections: "Draft · not executed", "Engineering baseline · not a scientific result". Never omit it to make a page look more finished.
- Badges wrap onto multiple lines at narrow widths rather than overflow.
