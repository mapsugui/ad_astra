# EntryList

Repository rows, not cards: type column, title + summary + badges, and a right-hand facts list (collection, date, size, license).

- Three columns ≥ 760px (150px / fluid / 210px), one column below. Rows are separated by `rule` hairlines.
- Facts show "undated", "—" or "not specified" when missing; size is never estimated.
- Every row carries its availability badge and, where the collection has one, its research-status badge.
