# EvidenceLadder

The four evidence levels as a numbered ladder with the record's current rung marked; shown on every candidate dossier.

- Consumer provides the rank (0 = unverified lead … 3 = established). Rungs below are "reached", the current one is inverted ink with `aria-current="step"`.
- Deliberately neutral: no green for higher levels, no progress-bar fill. Evidence levels describe evidence, not importance.
- Always pair with the working-ID Callout on the same page.
