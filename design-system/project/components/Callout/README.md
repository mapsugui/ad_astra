# Callout

A bordered note above or inside content: `--note` (accent rail; context such as "No discovery claims"), `--caution` (warn; withdrawals), `--draft` (hatched amber rail; draft campaigns only), plain (restricted items).

- Consumer provides a short bold `.callout-title` and one or two sentences.
- The draft callout's hatch is the only diagonal pattern in the system and means exactly one thing: not executed, no results.
- Quote the source when it states its own status ("The specification itself says: 'queued; not yet executed'").
