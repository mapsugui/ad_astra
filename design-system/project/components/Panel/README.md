# Panel

A bordered `surface` box for sidebar facts: record metadata, citation, related links, evidence ladder.

- Consumer provides: a `.panel-title` (mono kicker style) and one kind of content.
- Panels live in the right column of `.grid-2` (2fr / 1fr ≥ 900px, stacked below). Main-column content is never boxed; lift only what is secondary.
- Padding `s5` (`s4` on phones), border `rule`, corner `radius`. No shadow.
