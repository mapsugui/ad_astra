# Steps

A campaign's ordered analysis steps: zero-padded mono numbers joined by a dashed rail, each with its spec comment and the implementing module's status.

- Use only for real sequences (campaign DAG order). Numbering encodes order; do not use it for unordered lists.
- Consumer provides step name, the spec's own note, and the module-register match (StateChip + module path + status text), or "status unknown".
