# StatLine

A strip of build-time counts: mono label, large mono figure, one qualifier line.

- Consumer provides label, figure and a qualifier that says what the number counts and when ("draft, not executed", "recorded privately").
- Figures are counted at build time and captioned as such; never animate, tick up or call them "live".
- Use only where the counts are the point (home status). Zero is shown as 0, not hidden.
