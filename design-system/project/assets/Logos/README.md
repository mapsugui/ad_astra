# Logos

The Northern Cross mark: the five brightest stars of Cygnus as squares (Deneb top, Sadr centre, Albireo foot, the two wing stars) on the cross's two strokes. Copied from the site's inline header SVG and favicon; there is no separate wordmark — set "Cygnus" in `font-ui` 600 beside the mark.

- `cygnus-mark.svg` — ink `#15171c` (the `ink` token, light theme). Use on `bg` / `surface`.
- `cygnus-mark-light.svg` — ink `#e6e8ec` (the `ink` token, dark theme). Use on the dark grounds.
- `cygnus-favicon.svg` — `#f3f2ee` mark on a `#15171c` rounded tile; browser tab icon only.

In the site itself the mark is inline SVG in `currentColor`, so it follows `ink` in both themes. Minimum size 20px. Never add glow, gradients or extra stars.
