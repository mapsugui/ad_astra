Escalation (2026-09-25)#

Repeat candidate — unverified lead. The calibrated screen found persistent events in sector 96 at BJD 2460909.52–.68 whose depths (2766–2776 ppm) fall inside the 0.5–2× window of the catalogued depth (4431 ppm), ΔT ≈ 2554.4 d from the catalogued epoch (2458355.12, sector 02); 40 of 2554 period aliases remain allowed. docs/AGENT_RUNBOOK.md makes a repeat candidate an escalation: the evidence level is not raised here, and a reviewer should decide the follow-up. The hand tests done so far are in Reviewer notes; difference-image centroids, an eclipsing-binary check and the TOI/ExoFOP record are still open.

Points a reviewer should weigh: the cluster's four mid-times span only ≈ 0.16 d and sit at the very start of sector 96, so they are one contiguous feature rather than multiple transits; the recovered depth is ≈ 0.63× the catalogue's, which is within the window but not a close match; and the only other persistent event (sector 29, ≈ 740 d later) has a ~1.1–1.3σ centroid excursion. 40 aliases survive, so the period is not constrained by this data.

Reviewer notes (2026-09-25)#

Positive control passed: the sector-02 profile (sector02/normalized_series.csv) shows a flat-bottomed dip centred on the catalogued epoch (BJD 2458355.1186), recovered at 4431 ± 144 ppm against a catalogue depth of 4105 ppm. The screen left 5 persistent events; the runner raised a repeat candidate, so this is escalated above.

Hand checks:

  • 2460909.52119 / .53369 / .54064 / .67883 (sector 96) — the repeat-candidate cluster. The four mid-times span ≈ 0.16 d and sit at the very start of sector 96 (t starts 2460909.5136), so they are one contiguous feature, not four transits. Flux-centroid residual is ≈ 0.3–0.6σ (MOM_CENTR1 +0.0015 px vs sd 0.0049; MOM_CENTR2 −0.0030 px vs sd 0.0131).
  • 2459095.57383 (sector 29) — a separate persistent event ≈ 740 d after the catalogued epoch; broad and non-flat, with a centroid residual of ≈ 1.1σ in MOM_CENTR1 (+0.0152 px vs sd 0.0136) and ≈ 1.3σ in MOM_CENTR2 (−0.0228 px vs sd 0.0174) — a modest pointing excursion, not a clean transit.
  • Sector 69 was screened at a high threshold (k = 5.0) and returned 0 excursions, so it neither confirms nor excludes the alias periods.

Read as one sector-start feature plus a moderate-centroid event; not decided here. The record's lead/Unverified lead is left unchanged.
