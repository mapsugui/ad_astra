Reviewer notes (2026-09-25)#

Positive control passed: the sector-70 profile of normalized_series.csv shows a flat-bottomed dip centred on the catalogued epoch (BJD 2460231.5467), full width ≈ 12.3 h (catalogue duration 13.4 h), both SAP and PDCSAP; the recovered depth (1598 ± 24 ppm) is deeper than the catalogue's 1002 ppm, most simply read as dilution in the catalogue value rather than a different event. No repeat candidate was raised (period_aliases not_tested; no persistent event matches the catalogued depth), so no escalation.

The four persistent screen events were checked by hand against sectorNN/normalized_series.csv and the screen.json centroids:

  • 2459461.25748 / .26790 / .42763 (sector 42) — these three are one contiguous low-flux stretch, not three transits: each binned profile is a broad (≥ 0.3 d), shallow (~1000–2000 ppm) depression that drifts rather than showing a flat transit floor, and the three mid-times fall inside the same ~4 h window. SAP and PDCSAP track each other in shape but differ in amplitude. Nearest-excursion centroid residuals are within the local scatter (MOM_CENTR1 up to −0.0019 px vs sd 0.0017 px; MOM_CENTR2 up to −0.0023 px vs sd 0.0022 px), i.e. ≲ 1.1σ, with no coherent pixel shift. Read as a low-frequency systematic (scattered light / momentum-dump-like), not a transit.
  • 2460233.01006 (sector 70) — shallow (~600–1300 ppm), broad, non-flat depression ≈ 1.46 d after the catalogued epoch; centroid residual 0.4σ (MOM_CENTR2 −0.0063 px vs sd 0.0163 px). Not a repeat of the catalogued transit.

Neither group is vetted for blends, backgrounds or pointing; both remain at most unverified leads. Catalogue cross-match was answered by all four services this run (SIMBAD returned HD 715), so no service-outage caveat applies.
