Escalation (2026-09-25)#

Repeat candidate — unverified lead. The calibrated screen found persistent events in sector 61 (BJD 2459973.46–.58) and sector 88 (BJD 2460697.46–.70) whose depths (2196–3099 ppm) fall inside the 0.5–2× window of the catalogued depth (3292 ppm). Both lie at ≈ 724.0 d from the catalogued epoch (2459249.55, sector 34), so a single period P ≈ 724 d would place all three. docs/AGENT_RUNBOOK.md makes a repeat candidate an escalation: the evidence level is not raised here, and a reviewer should decide the follow-up. The hand tests done so far are in Reviewer notes; difference-image centroids, an eclipsing-binary check and the TOI/ExoFOP record are still open.

Points a reviewer should weigh: the two clusters are each internally narrow (≈ 0.05–0.25 d), so they are one feature per sector, not multiple transits; the recovered depth exceeds the catalogue's by ≈ 1.4×, which dilution alone may not explain; and the runner's alias table does not settle the period (0/723 allowed for the first event, 26/723 for the others). Only three epochs are available and they are all one 724 d grid, so the alias set cannot be narrowed from this data alone.

Reviewer notes (2026-09-25)#

Positive control passed: the sector-34 profile (sector34/normalized_series.csv) shows a flat-bottomed dip centred on the catalogued epoch (BJD 2459249.5471), recovered at 3292 ± 79 ppm against a catalogue depth of 2315 ppm. The screen left 34 persistent events; the runner raised a repeat candidate, so this is escalated above.

Hand checks:

  • The repeat-candidate cluster sits in sector 61 (2459973.46 / .53 / .56 / .58) and sector 88 (2460697.46 / .52 / .53 / .70) — two groups, each internally spanning only ≈ 0.05–0.25 d, i.e. one contiguous feature per sector rather than several transits.
  • The key fact is the spacing: the catalogued epoch (2459249.56, sector 34) and the two clusters are separated by ≈ 724.0 d each (2459249.56 → 2459973.56 → 2460697.52). A single period P ≈ 724 d would place all three, which is why the runner flagged a repeat rather than a chance coincidence.
  • Flux centroids at the two clusters are consistent with the local scatter — sector 61 residual ≈ 0.0000 px (sd 0.0006/0.0008) and sector 88 MOM_CENTR1 +0.0026 px (sd 0.0025), MOM_CENTR2 −0.0002 px (sd 0.0065) — so no pointing excursion accompanies them.

Not decided here: the runner's alias table leaves 0/723 allowed for the first event and 26/723 for the others, and a 724 d period is only one of the surviving interpretations. Difference-image centroids, an eclipsing-binary / blend check and the ExoFOP record are open. The record's lead/Unverified lead is left unchanged.
